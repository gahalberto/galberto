# 📸 Imagem do Perfil - Gabriel Alberto

## 📋 Instruções para Adicionar a Foto

A página "Sobre" está configurada para exibir uma foto profissional do Gabriel Alberto.

### 📁 Localização do Arquivo

Coloque a imagem em:
```
public/images/gabriel-alberto.jpg
```

### 🎨 Especificações da Imagem

**Recomendações:**
- **Formato:** JPG ou PNG
- **Proporção:** 3:4 (vertical/retrato)
- **Resolução mínima:** 1200x1600px
- **Tamanho máximo:** 2MB (otimize antes de adicionar)

### 📐 Estilo Fotográfico Recomendado

**Descrição visual:**
- Retrato profissional em ambiente urbano moderno
- Gabriel usando terno azul marinho ou camisa social azul clara
- Fundo com elementos arquitetônicos de São Paulo (edifícios modernos) desfocados
- Iluminação natural suave vinda da esquerda
- Expressão confiante e acessível, com leve sorriso
- Ambiente acolhedor e profissional

**Alternativas de cenário:**
1. **Escritório moderno:** Mesa com vista para a cidade, decoração minimalista
2. **Varanda/terraço:** Com vista para São Paulo ao fundo, luz natural
3. **Ambiente neutro:** Parede de tijolos ou concreto aparente, plantas decorativas

### 🏷️ Alt Text (Já configurado)

A imagem já tem o alt text configurado para SEO e acessibilidade:
```
"Gabriel Alberto, consultor imobiliário CRECI 267769, em retrato profissional com terno azul em ambiente urbano moderno de São Paulo"
```

### ⚠️ Se a Imagem Não For Adicionada

Se a imagem não existir, o Next.js mostrará um erro. Você pode:

1. **Adicionar a imagem** seguindo as especificações acima
2. **Usar uma imagem placeholder temporária** até ter a foto profissional
3. **Comentar a seção da imagem** no código se preferir não exibir foto ainda

### 🔧 Como Adicionar

1. Prepare a foto seguindo as especificações
2. Otimize a imagem (reduza tamanho se necessário)
3. Renomeie para `gabriel-alberto.jpg`
4. Coloque em `public/images/gabriel-alberto.jpg`
5. A imagem aparecerá automaticamente na página

---

**Nota:** A página está pronta e funcionando. Basta adicionar a imagem no local correto.
